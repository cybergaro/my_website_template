# 🌐 Francesco Garofolo - Personal Website Template

Welcome to the source code repository for my personal website! 👋
This project hosts the template and necessary files for publishing my digital portfolio and online curriculum. 🚀

## 📖 Project Description

The website is designed as a static *Single Page Application* to clearly and concisely present the author's professional profile.

Inside the page, you will find the following descriptive sections:
* **Hero Section**: Introduction and welcome.
* **About Me**: An overview of my career, passions, and personal background.
* **Education**: A timeline of my educational journey, from high school to university.
* **Experience**: Details on past and current work experiences, both as an employee and a freelancer.
* **Certifications**: A list of titles and certifications obtained in the IT field.
* **Contacts**: Direct contact information and links to social profiles.

## 🛠️ Tech Stack

The project is built with native web technologies to ensure lightweight performance and universal compatibility:

* ![HTML5](https://img.shields.io/badge/html5-%23E34F26.svg?style=for-the-badge&logo=html5&logoColor=white) **HTML5**: Semantic page structure.
* ![CSS3](https://img.shields.io/badge/css3-%231572B6.svg?style=for-the-badge&logo=css3&logoColor=white) **CSS3**: Custom styling and responsive layout for desktop and mobile.
* ![JavaScript](https://img.shields.io/badge/javascript-%23323330.svg?style=for-the-badge&logo=javascript&logoColor=%23F7DF1E) **JavaScript**: Handling interactivity (smooth scroll) and tracking.
* **External Libraries**: Integration with FontAwesome for icons and Google Fonts (*Montserrat*).
